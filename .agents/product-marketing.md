# Product Marketing Context — Sprind

## What it is
Sprind is an AI-powered vocabulary and language-learning Progressive Web App (PWA), also shipped as native iOS and Android apps via Capacitor. It teaches the words and phrases people actually use — greetings, travel, food, work, common phrases — across 50 languages.

Note: the repo folder is named `vocabworld`, but the product name is **Sprind**. Never use "VocabWorld" in copy.

## Primary action
Get visitors to start learning — sign up / pick a language and start the first lesson. Secondary action: convert free users to a paid subscription.

## Audience
- Self-directed language learners of any proficiency level (no CEFR/level gating).
- Practical/casual learners who want real-world usable vocabulary, not academic grammar drills.
- Mobile-first users; learning happens in short daily sessions.
- Users pick both a native language and a target language at onboarding.

## Product / offer
- 50 supported languages.
- Native audio pronunciation for every word.
- Spaced repetition for vocabulary review.
- Daily streaks and progress tracking, synced in real time.
- Topic-based quizzes (Greetings, Numbers, Time, Travel, Food, Work, etc.).
- Leaderboards.
- Saved words / playlists.
- Offline mode (full PWA caching — works without a connection).
- Push notifications for streak reminders.

**Differentiation:** practical, real-use vocabulary (not textbook grammar); works offline; native pronunciation built in; cross-platform (web + iOS + Android) with synced progress.

**Key transformation:** go from zero vocabulary in a language to being able to handle everyday real-life situations (ordering food, greeting people, traveling, basic work conversation).

## Pricing / monetization
Freemium model:
- Free tier: first 3 topics (Greetings, Numbers, Time).
- Premium: $5.99/month or $49.99/year — unlocks all topics/languages.
- Billed via RevenueCat (Apple/Google in-app purchase) and Stripe.
